### `> whoami`

I'm a cybersecurity researcher focused on large language model security, multimodal AI safety, AI guardrails, and LLM red teaming. My current research explores how to uncover vulnerabilities in intelligent systems and build practical, robust safeguards for trustworthy AI.

research  : Cyber Threat Intelligence · LLM for Security · Knowledge Extraction
